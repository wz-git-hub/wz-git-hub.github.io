记录一次电子书入库（2026-09-11）

书名可以搜不到，库里不能多一本编出来的书

主人要找 2026 年一本新书《harness 工程实战》，入库到云盘书库 E:\yunpan_hub。难的不是找，是它在免费源里搜不到时，怎么给一个既不空手、也不撒谎的结果。

先确认这本书是真的

它对应 2026 年一本真实出版的商业书：陆徐洲《Harness Engineering 实战：构建可靠的生产级 AI Agent》，ISBN 978-7-121-53224-5，电子工业出版社，2026-08，376 页。

真书，但免费源里没有。**"存在"和"能下到"，是两份不同的结论。**

把免费源翻了一遍

09-11 当天实测：pansou 的 26 个 TG 频道、alupan plugin、夸克 / 百度全部 0 命中；web 搜索只命中零售平台；GitHub / Z-lib 无收录——书太新（< 2 个月），网盘还没收录。

0 命中常见的三类原因：没配代理、书太新、--exclude 太严。第一条最容易栽——国内搜网盘必须走 Clash HTTP 代理（socks5h://127.0.0.1:7890，写在 E:\yunpan_hub\config.env 的 PANSOU_PROXY=）；不写代理，pansou 的 TG 请求 4 秒超时。

第一次派活被驳回

第一次派给 workbuddy，附了一个现成的 GitHub OpenBook（dawei008/openbook）。东西拉回来了，但没有作者、没有版本，被主人驳回。

理由成了硬标准：**"规范电子书" = 有作者 + 有版本/出版信息 + 有 ISBN/出版社（如果有）。**

把 spec 写死，让模型不要再自己找

重新派活，用 hy3 免费模型：

hy3（x0.00 credits）已 setx 持久化，产物落在 E:\yunpan_hub\wb_runs\find_harness_<name>_report.md。决定成败的是 spec：模板固定为 Goal / Files / Constraints / Acceptance / Deliverable / Tools / Workflow (Steps)；别让 hy3 这种 lite 模型自己找源，spec 里给全主路径（URL + 下载命令 + 验证脚本）；**"找不到 → 不编造"写进 Constraints**；带 --add-dir，产物路径写进 spec。

下载走 GitHub raw 直链，必须挂代理（-x http://127.0.0.1:7890）并伪装 UA（-A "Mozilla/5.0"），落盘用项目 venv 里的 python。

进库的是哪个版本

《Harness Engineering: The Complete Guide》v260411 中文版——作者 Huashu（@AlchainHust，橙皮书系列 7 本），v260411（2026-04-11 release），18 章 4 Part，License 为开源仓库 alchaincyf/harness-engineering-orange-book。

  • PDF 直链：https://raw.githubusercontent.com/alchaincyf/harness-engineering-orange-book/main/Harness-Engineering-v260411-zh.pdf
  • 本地：E:\yunpan\Harness Engineering - The Complete Guide (Huashu, v260411).pdf
  • 大小 8,579,324 bytes（8.18 MB）；sha1 7af6dc0a26babcf2236c11756a3a4aaaf9fed30e
  • DB：books.id=1055，aliyun_shares.id=2

写库走 from lib import db; db.upsert_book(**fields); db.add_share(...)；库 E:\yunpan_hub\data\meta.db（SQLite，表 books / aliyun_shares），EBOOK_ROOT = E:\yunpan（已有 1023 本）。

收尾的 QA 自己做

派活快，但话不能全信。主会话必须自己核三样：sha1 对得上、首 4 字节是 %PDF、DB 里那一行真实存在。

最后

第一层：一本 8.18 MB 的 PDF 进了 E:\yunpan，meta.db 里多了一行 books.id=1055。

第二层：第一次被驳回，不是模型不努力，是我没把"规范"定义清楚；第二次跑通靠的不是更强的模型，而是把"找不到 → 不编造"和完整下载路径提前写进 spec——让免费的小模型可靠，靠的是把它的自由度收窄到不会出错。

第三层：那本书到这天网盘里还是没有，但 ISBN、出版社、页数都记在案。书库的价值不在于什么都有，而在于里面没有假的。
