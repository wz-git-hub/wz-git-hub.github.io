五个候选因子验证，只留下做空高动量一条腿（2026-08-14）

发表于2026-08-14|更新于2026-10-22|量化策略
|阅读量:

一天跑完五个方向，最后只剩一条腿站着。

08-14 把手上所有候选方向一次性验证完：低动量做多、24h 动量跟随、量价因子新腿、factor_ic 最优形态、长周期反转。五个方向，五份报告。

框架是同一套：12 币池、IS/OOS 切在 2026-07-31（之后为真样本外）、24h 持有、5% 止损 / 15% 止盈、120min 冷却、手续费 1bp。 只换信号，不换尺子。

结论是：五个方向里，四个被否，只剩"做空高动量"这一条腿。

一份报告，一个拒绝理由

那天先把"怎么算验证通过"定死了。评估分三条：回测配置一致性（权重 0.3）、结论数据支撑（0.4）、建议可执行性（0.3）。也就是说，一个方向的结论，光看全样本收益没用，必须有全样本 + 样本内 / 样本外多维度的支撑。

剩下的就是一份份看。

低动量做多：−29.63% 到 −54.01%

四个配置（A 上涨限定 TOP1 / B 不限 regime TOP1 / D1 上涨限定 TOP2 / D2 上涨限定 TOP3），笔数从 74 到 222，总收益 −25.82% 到 −54.01% 全负。胜率全部贴着 50%。

没有对称收益，不能作为策略腿加入。

24h 动量跟随：−49.56%

即便限定在上涨 regime，做多最高动量的币，**全样本收益 −49.56%**；仅看上涨 regime 那一段 −50.50%；上涨 regime 入场那一档 −7.04%，不限 regime 入场 −45.73%，TOP_N=2 / 3 更差（−60.6% / −68.9%）。

和 factor_ic 对照最清楚：SHORT 高动量 +34.9% ↔ 动量跟随 LONG 高动量 −49.6%。这批币在 24h 频段均值回归占优，跟动量必亏。方向无效，被数据拒绝。

量价新腿：SHORT 全正，但它不是新 alpha

量价因子（volume_zscore 和 cvd_slope_24h）各测了反转和跟随两个方向，共 4 个配置，每配置只有 22 笔真样本外：

配置 LONG 腿 SHORT 腿 配对
VOL 反转（低量 L / 高量 S） −10.00% +3.96% −6.44%
VOL 跟随（高量 L / 低量 S） −4.24% +10.49% +5.81%
CVD 反转（低 CVD L / 高 CVD S） −0.59% +4.56% +3.93%
CVD 跟随（高 CVD L / 低 CVD S） −4.78% +1.58% −3.28%

全样本上看，SHORT 腿 4 个配置全正：VOL 反转 +36.9% / VOL 跟随 +24.0% / CVD 反转 +46.3% / CVD 跟随 **+94.4%**；而 LONG 腿全负（−55% 到 −24%）。

看起来很诱人，但结论是不新增，三条理由：

  1. LONG 腿在所有配置全负——和"LONG 已死"一致，量价因子也救不出正的多头腿。
  2. SHORT 腿是唯一的稳定信号，但它和现动量 SHORT 是同一个 alpha——都是"做空高关注 / 放量币"的反转，高度相关，不是独立的分散腿。加进去只是把同一笔赌注加倍。
  3. **CVD 跟随全样本 SHORT 高达 +94.4%，但样本外塌到 +1.58%**——典型的 regime 过拟合，不可信。

报告落在 _tmp_vol_cvd_bt_report.txt（含 4 配置 × 全样本 / IS / OOS / 分腿 / fee 敏感性完整明细）。

长周期：24h / 72h / 168h，一个方向地衰减

最后一个问题是："拉长到 72h / 168h，是不是就对称了？"报告（_tmp_long_horizon_reversal_bt_report.txt）给的判据表：

窗口 SHORT 高动量腿 LONG 低动量腿 配对
24h +34.9% −38.1% −16.5%
72h +14.0% −48.1% −40.8%
168h −15.1% −24.6% −36.0%
  • LONG 低动量腿在 24 / 72 / 168h 全为负（−38% → −48% → −25%），越拉越长越亏——"对称补完"的假设被彻底否决。
  • SHORT 高动量腿随窗口衰减（+35% → +14% → −15%），整个反转溢价在 168h 蒸发。
  • 稳健性上有一点很关键：72h 那一档里，SHORT 和 LONG 用的是完全相同的 5% / 15% 止损止盈，一个正一个负——符号背离不是止损参数的假象，是 IC 本身的单向性。

factor_ic 的最优形态：只剩一条腿

五个方向看完，收口很清楚：factor_ic 唯一 durable 的 alpha，就是 24h SHORT-only 反向动量。

  • 维持现状：24h SHORT-only + $80 验证仓，让 A/B（自 08-10）继续安静攒样本。
  • 不加低动量做多、不加长周期、不加量价新腿。
  • 下一步若真想找新腿，得离开量价族（比如 funding / 基差、跨所价差）——但那已经超出当前因子库的范围。

最后

那天五个方向跑完，收获得分三层。

最表面的是五份报告——一份通过、四份被否，落成可以复盘的证据。

中间一层是那条判据：一个方向是否成立，不看它全样本多漂亮，看它样本外还剩多少。 CVD 跟随的全样本 +94.4% 和样本外 +1.58%，就是这条判据最好的反例。

最里面一层，是接受"只剩一条腿"这件事。 跑了一天，最后能加的只有零条——这从"找收益"的角度看是失败的，但从"搞清楚自己赚的是哪一笔钱"的角度看，是那天最值钱的结论。知道自己手里的 alpha 只有一条、且知道它为什么只有一条，比手里攥着五条说不清来源的腿，要稳得多。
